# 🐍 Section 01 — Python Fundamentals

This section contains the foundational Python labs in the Python Programming Labs repository.

The labs introduce the Python environment, basic syntax, variables, data types, expressions, conditional statements, loops, core data structures, and functions.

## 🎯 Section Objective

By completing Labs 01–10, you will build a strong foundation in Python programming and prepare for the more advanced topics covered in later sections.
